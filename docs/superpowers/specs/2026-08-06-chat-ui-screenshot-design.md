# 聊天 UI 与截图体验优化设计

## 目标

优化四类体验问题：

1. 组织结构树的层级、折叠和长名称展示不够清晰。
2. 消息操作需要参考飞书，悬浮消息即可看到常用操作，而不是先点三个点。
3. 截图确认后应作为待发送图片进入聊天输入区，而不是直接发送或只显示一个难以继续操作的缩略图。
4. 外部截图工具复制到系统剪贴板的图片可以直接粘贴到聊天输入区。

本次不改变消息协议、组织结构接口和图片上传接口，只复用现有的消息发送与附件队列能力。

## 交互设计

### 组织结构

- 保留现有的企业根节点、OU 分组和部门树数据结构。
- 左侧树区域使用可伸缩宽度，默认比当前 240px 更宽，避免深层节点被迫换行。
- 每个节点使用固定行高并单行显示，超长名称以省略号截断，完整名称通过 `title` 提供。
- 只有存在子节点的节点显示展开/折叠箭头；叶子节点不显示空箭头占位。
- 使用稳定的缩进和层级导引线表达父子关系；根节点、OU 分组和普通部门使用不同但克制的字重/颜色。
- 悬浮态只改变背景和文字颜色，选中态使用浅色背景和主题色文字，不增加明显的布局跳动。
- 保留默认展开行为，用户可以单独折叠节点；不引入额外的展开状态持久化。

### 消息操作条

- 消息行悬浮且当前不在多选模式时，直接显示紧凑的悬浮操作条。
- 操作条放置在消息气泡外侧，发送方和接收方分别镜像定位，不挤压气泡内容。
- 常用操作直接展示：回复、转发、复制（文本消息）。
- 多选、撤回等低频操作收进“更多”菜单；保留现有操作权限和回调。
- 操作条采用轻边框、圆角、浅阴影、统一图标按钮尺寸，悬浮按钮有主题色反馈。
- 鼠标从消息气泡移动到操作条时，操作条保持显示；菜单打开时即使鼠标离开消息行也不立即消失。

### 截图进入待发送队列

- 截图流程仍保留当前全屏抓取、区域选择、矩形、画线和文字标注能力。
- 截图编辑器的确认动作生成原始分辨率 PNG，并转换为 `File`。
- 确认后调用聊天输入区已有的 `addPendingFiles`，关闭编辑器，不调用 `sendMessage`。
- 输入区继续使用已有附件预览和删除逻辑；用户可以继续编辑文本，最后点击“发送”统一发送图片和文字。
- 截图文件使用稳定的 PNG 文件名和 `image/png` 类型，确保和文件选择、拖拽图片走同一上传分支。
- 编辑器按钮文案由“确认”调整为“添加到输入区”，避免用户误以为会立即发送。

### 系统剪贴板图片粘贴

- 保留浏览器 `ClipboardEvent` 中标准 `File` 的优先处理逻辑。
- 当粘贴事件没有文件时，通过 Electron IPC 从系统剪贴板读取图片位图。
- 主进程仅在剪贴板存在图片时返回 PNG data URL；没有图片时返回空值，不干扰文本粘贴。
- 渲染进程将 data URL 转换为 `File` 后加入 `pendingFiles`，不立即发送。
- 普通文本粘贴继续交给 CKEditor 默认处理；只有识别到图片文件或系统图片时才阻止默认事件。

## 代码边界

- 组织结构：`src/pages/contact/organization/index.tsx`，优先使用现有 Ant Design `Tree` 的 `titleRender`、`switcherIcon` 和 className 定制，不改接口数据。
- 消息操作：`src/pages/chat/queryChat/MessageItem/index.tsx` 与 `message-item.module.scss`；以现有 `actionItems` 为行为来源，减少重复菜单逻辑。
- 截图队列：`src/pages/chat/queryChat/ChatFooter/index.tsx` 与 `ScreenshotCropper.tsx`；复用 `PendingFileItem` 和 `addPendingFiles`。
- 剪贴板 IPC：`electron/constants/index.ts`、`electron/main/ipcHandlerManage.ts`、`electron/preload/index.ts`、`src/types/globalExpose.d.ts`。
- 不修改组织结构 API、消息发送 API 或 SDK 数据模型。

## 失败与边界处理

- 截图权限不足时沿用现有错误提示并恢复窗口显示状态。
- 剪贴板读取失败或无图片时静默回退到普通文本粘贴，不弹出错误提示。
- 截图确认前取消编辑器，不新增待发送附件。
- 删除待发送图片时释放对应的 object URL，沿用现有清理逻辑。
- 操作条只在非禁用、非多选状态显示；消息原有的撤回、转发、回复权限判断不改变。

## 验收标准

- 深层组织结构名称不再因为树宽度不足而逐字换行，展开/折叠箭头和层级关系清晰。
- 鼠标悬浮消息时直接看到飞书式操作条，常用操作无需打开三个点菜单。
- 截图编辑器点击确认后，图片出现在聊天输入区的待发送附件区域；点击发送前不会发出消息。
- 使用系统截图工具复制图片后，在聊天输入区按 Ctrl/Cmd+V 可以看到待发送图片预览；粘贴普通文本仍然正常。
- TypeScript 构建和现有 lint 不因本次改动新增错误。
